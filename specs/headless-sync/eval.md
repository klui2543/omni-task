# เกณฑ์ผ่านตก

## เทสอัตโนมัติ (`gradle :shared:allTests` ในเครื่อง, และ Build APK ใน CI)
1. `HeadlessSync.outcome`: errmsg มีคำว่า allow-external-apps = ตั้งค่าไม่ครบ (NotAllowed, ไม่ว่า err เป็นเท่าไร), exit 127 หรือข้อความว่าไม่มีสคริปต์ omni-sync.sh = ยังไม่ได้ติดตั้ง (NotSetUp), err อื่นที่ไม่ใช่ -1 = ล้มเหลวพร้อม errmsg (Failed), exit 0 = สำเร็จ, exit 75 = มีรอบอื่นถือกุญแจอยู่ (Busy: ไม่บอก ไม่ล้างสถานะรอ), exit อื่น = ล้มเหลวพร้อมบรรทัดท้าย stderr ห้ามคืนสำเร็จเมื่อไม่มีผล (ทุกค่าเป็น null)
2. `HeadlessSync.due`: สั่งซ้ำภายใน 20 วินาทีไม่ได้ เกินแล้วได้ ครั้งแรกได้เสมอ และเวลาถอยหลัง (นาฬิกาเปลี่ยน) ได้
3. control test: ย้อนเงื่อนไขใน outcome ให้คืนสำเร็จทุกกรณี เทสข้อ 1 ต้องตก
4. ไม่มี java.time ใน shared ที่เพิ่ม
4.1 สวิตช์ทางใหม่ (`TermuxSync.on`) ปิด เว้นแต่โฟลเดอร์ vault ที่ Omni อ่านชื่อ OmniVault (`HeadlessSync.isSyncedFolder`) และมี Termux และได้สิทธิ์แล้ว ก่อนย้ายโฟลเดอร์ทุกอย่างเหมือนก่อนมีฟีเจอร์นี้ (ไม่สั่งซิงก์ ไม่ขอสิทธิ์) และลิงก์เปิดโน้ตไม่ใส่ชื่อ vault เมื่อโฟลเดอร์คือ OmniVault (`HeadlessSync.obsidianVault`)

## ตรวจโค้ด (ผู้ตรวจ)
5. เมื่อทางใหม่เปิดและซิงก์สำเร็จ ไม่มีทางไหนเรียก `obsidian://open` อัตโนมัติ
6. เมื่อทางใหม่ปิด พฤติกรรมเดิมทุกอย่างคงเดิม (diff ไม่แตะทางเดิมนอกจากการเลือกทาง)
7. error ทุกทาง (startForegroundService โยน, ผลกลับมาผิด, ไม่มีผลกลับใน 3 นาที) ขึ้นข้อความให้ Klui
8. ซิงก์เสร็จแล้วอ่าน vault ใหม่ครั้งเดียว ไม่วนสั่งซิงก์ซ้ำไม่จบ
9. ไม่มีขีดยาวหรือจุดกลางในข้อความใหม่

## Klui ลองใน APK
10. ติดตั้ง Termux และวางชุดคำสั่ง ซิงก์ครั้งแรกจบ ได้โฟลเดอร์ vault ใหม่
11. เลือกโฟลเดอร์ใหม่ใน Omni กดอนุญาตสิทธิ์ Termux แล้วงานขึ้นครบ
12. รอรอบเลขาถัดไป เปิด Omni: Obsidian ไม่เด้ง และเห็นของใหม่จากเลขา
13. ติ๊กงานใน Omni ออกจากแอป แล้วดูในแอป Obsidian (หรือพีซี) ว่าติ๊กขึ้น
