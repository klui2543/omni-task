Omni Task: งาน Art and design หลายแบบให้เลือก

ทุกอย่างในหน้านี้เป็นแบบร่างให้ดูและเลือก ยังไม่ได้แตะโค้ดแอป ตัวละครอิงจาก rpg-design.md ข้อ 3, 9, 10, 14 และตารางตัวละครใน rpg-story.md (Mascot 5 ตัว, ลีโอ, เซลีน, มาสเตอร์ออร์ริน, ราชาผัดวัน, ผู้เล่น) บอกเลขแบบที่ชอบ เช่น "ไอคอน B, สี 3, หน้าจอ C, ตัวละครสไตล์ 3" แล้วค่อยลงมือทำจริง

1 ไอคอนและโลโก้2 ธีมและสี3 หน้าจอ4 ตัวละคร5 Empty state6 Style guide

1. ไอคอนและโลโก้ (4 แบบ)

ไอคอนปัจจุบันเป็นวงแหวนความคืบหน้ากับเครื่องหมายถูกบนพื้นดำ ทั้ง 4 แบบอยู่ในโซนปลอดภัย 66/108 ของ adaptive icon แสดงเป็นวงกลม สี่เหลี่ยมมน และขนาดเล็ก 48 กับ 24 px

2. ธีมและสีระบบ (4 แบบใหม่ เทียบกับของเดิม 2 แบบ)

ทุกชุดครบ bg, card, เส้น, text, muted, accent และสีงานด่วน/สำคัญ ชุด 1 ถึง 4 ใช้กับ Palette ใน Theme.kt ได้ตรงๆ ตรวจ contrast บนสี card แล้ว (text / muted / faint / accent): Forest 15.6 / 7.7 / 5.2 / 10.3, Dawn 15.1 / 5.7 / 4.9 / 4.9, Deep Sea 15.0 / 7.3 / 5.4 / 9.5, Ember 15.6 / 7.2 / 5.3 / 8.6 ผ่าน 4.5:1 ทุกค่า

ไอเดียเสริม: accent ตามเผ่า (เมื่อเปิดเกม Omni Quest)

ใช้ธีมเดียว แต่ accent เปลี่ยนตามเผ่าของผู้เล่น UI จึงเปลี่ยนบรรยากาศโดยไม่ต้องทำหลายธีม

3. หน้าจอวันนี้ (4 เลย์เอาต์)

หน้าเดียวกัน ข้อมูลเดียวกัน เลย์เอาต์และสีต่างกัน แต่ละแบบจับคู่กับธีมที่เหมาะ แต่สลับธีมได้อิสระ

4. ตัวละครทั้งหมด (3 สไตล์ x 10 ตัว)

ข้อ 14 กำหนดให้ภาพจริงของ Mascot, NPC และภาพเนื้อเรื่องมาจาก AI วาด และให้ใช้ภาพแทนชั่วคราวระหว่างพัฒนา ชุดนี้ทำสองหน้าที่: เป็นภาพแทนชั่วคราวที่ใช้ได้เลย และเป็นต้นแบบรูปทรงกับสีให้ style guide (ข้อ 6) สีประจำเผ่า: อัคนี ส้มไฟ, จันทรา ม่วงน้ำเงินดาว, วายุ เขียวมิ้นต์, ธารา ฟ้าน้ำ, พฤกษา เขียวใบไม้

5. ภาพประกอบและ Empty state (3 สไตล์ x 3 หน้า)

ใช้ Mascot แทนภาพว่างๆ ข้อความเป็นน้ำเสียงเดียวกับเกม ไม่ตำหนิ ไม่ใช้ขีดยาวหรือจุดกลาง

6. Style guide สำหรับให้ AI วาดภาพจริง

ข้อ 14 ต้องมี prompt แม่แบบ สีประจำเผ่า และภาพอ้างอิงต่อตัวละคร ตัวอย่างนี้ผูกกับสไตล์ที่เลือกในข้อ 4 เก็บภาพที่ผ่านแล้วเป็นภาพอ้างอิงของตัวละครนั้น และเก็บใบอนุญาตใน licenses/ ห้ามใช้ภาพ ชื่อ หรือเพลงของ Ragnarok
