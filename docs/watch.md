# Omni บน Galaxy Watch

แอปเล็กๆ บนนาฬิกา ทำอย่างเดียวคือปลุกตื่นนอน มือถือส่งเวลาตื่นไปจากการ์ดนอน (ปุ่ม "ปลุกที่นาฬิกา") แล้วนาฬิกาจะสั่นปลุกเอง มือถือไม่ดังและไม่สั่น

## ลงแอปบนนาฬิกา (ครั้งแรก)

Obtainium ลงแอปบนนาฬิกาไม่ได้ ต้องใช้ ADB ทาง Wi-Fi ซึ่งทำจากมือถือได้เลย ไม่ต้องใช้คอม

1. ที่นาฬิกา: การตั้งค่า > เกี่ยวกับนาฬิกา > ข้อมูลซอฟต์แวร์ > แตะ "เวอร์ชันซอฟต์แวร์" 5 ครั้ง เพื่อเปิดตัวเลือกนักพัฒนา
2. การตั้งค่า > ตัวเลือกนักพัฒนา > เปิด "การแก้ไขข้อบกพร่อง ADB" และ "แก้ไขข้อบกพร่องผ่าน Wi-Fi" (นาฬิกากับมือถือต้องอยู่ Wi-Fi เดียวกัน)
3. ในหน้า "แก้ไขข้อบกพร่องผ่าน Wi-Fi" แตะ "จับคู่อุปกรณ์ใหม่" จะได้ IP, port และรหัสจับคู่
4. ที่มือถือ: ลงแอป "Wear Installer 2" (หรือ Bugjaeger) จาก Play Store แล้วจับคู่ด้วย IP, port และรหัสจากข้อ 3
5. โหลดไฟล์ `omni-watch-0.2.N.apk` จากหน้า release ล่าสุดของ repo นี้ แล้วสั่งติดตั้งผ่านแอปในข้อ 4
6. ปิด "การแก้ไขข้อบกพร่อง ADB" บนนาฬิกาเมื่อเสร็จ (ช่วยประหยัดแบต)

แอปบนนาฬิกาแทบไม่ต้องอัปเดต ลงครั้งเดียวพอ เว้นแต่ release note บอกว่าต้องลงใหม่

## Obtainium บนมือถือ

ตั้งแต่ release นี้ แต่ละ release มี 2 ไฟล์ ให้ตั้ง Obtainium ของ Omni Task:
แก้ไขแอป > "Filter APKs by regular expression" ใส่ `omni-task` เพื่อให้เลือกไฟล์ของมือถือเสมอ

## ใช้งาน

- การ์ดนอนบนมือถือ: แตะ "ปลุกที่นาฬิกา HH:mm" ปุ่มจะเป็นสีเขียว "นาฬิกาจะปลุก HH:mm" แตะซ้ำเพื่อยกเลิก
- เปลี่ยนเวลาตื่นหลังตั้งแล้ว มือถือจะส่งเวลาใหม่ให้เองตอนเปิดหน้าโฟกัส
- ตอนปลุก: กด "หยุด" หรือ "+5 นาที" ถ้าไม่กดเลย สั่น 10 นาทีแล้วเลื่อนเอง 5 นาที สูงสุด 3 รอบ
- ถ้าปุ่มขึ้นสีแดง "ส่งไม่ถึงนาฬิกา": ดูว่านาฬิกาเชื่อมกับมือถืออยู่และลงแอปแล้ว
