# ชื่อโปรเจกต์

ตารางชื่อโปรเจกต์ที่ใช้ใน Omni (Ygdrasil) เลขาและ Claude ทุกเซสชันใช้ชื่อในช่อง "ชื่อใน Omni" เท่านั้นเวลาเขียนแท็กในงาน (Claude log, Omni note) เพื่อให้งานเข้ากิ่งเดียวกับที่ Klui ใช้ ไม่แตกเป็นโปรเจกต์ซ้ำ
แท็กใช้ชื่อเต็มก่อน แล้วต่อด้วยกิ่งย่อยด้วย `/` เช่น `#Siriraj/ตารางเวรเภสัช/wording`

| ชื่อใน Omni | ชื่อเรียกอื่นที่ Klui หรือ Claude อาจใช้ |

| Siriraj/ตารางเวรเภสัช | rxshift, asstrxshift, ระบบแลกเวร, ตารางเวร |

## กติกา
- เจอชื่อเรียกอื่นในคอลัมน์ขวา ให้แปลงเป็นชื่อใน Omni ก่อนเขียนแท็ก
- โปรเจกต์ใหม่ที่ไม่อยู่ในตาราง: เลือกชื่อสั้นภาษาไทยหรืออังกฤษที่ Klui ใช้พูด เพิ่มแถวลงตารางนี้ และบอก Klui ในสรุปรอบ (ถ้าชื่อไม่แน่ใจ ถามก่อน)
- ตารางนี้ Claude แก้ได้ แต่ห้ามเปลี่ยนชื่อในคอลัมน์ซ้ายของแถวเดิมโดยไม่ถาม Klui
- งานเรื่องแอป Omni และเลขาเป็นโปรเจกต์ Omni อันเดียว กิ่งย่อยที่ใช้: Omni/เลขา (เลขาและ Claude log), Omni/เลขา/คุมเลขา, Omni/assistant, Omni/calendar, Omni/focus, Omni/voice, Omni/ygdrasil, Omni/log, Omni/งานของฉัน กิ่งใหม่ตั้งชื่อสั้นตามเรื่อง
