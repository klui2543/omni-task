## 3. กล่องจดหมายจาก Claude Chat และ Cowork

Chat และ Cowork เขียนเข้า vault ไม่ได้ และเลขาอ่านแชตเหล่านั้นไม่ได้ (ทดสอบแล้ว 2026-10-22: งานตั้งเวลาของ Cowork ไม่มีเครื่องมือค้นแชตเก่า) จึงต้องบอก "บันทึก" เอง จะพิมพ์หรือพูดตอนจบแชตเสียงก็ได้ แชตเล็ก ๆ ที่ไม่มีอะไรต้องเก็บไม่ต้องบันทึก

```mermaid
sequenceDiagram
  actor K as Klui
  participant C as Claude Chat หรือ Cowork
  participant D as Drive: Claude inbox
  participant S as เลขา
  participant V as Obsidian vault
  K->>C: พิมพ์ "บันทึก"
  C->>D: สร้างไฟล์ใหม่ 1 ไฟล์ รูปแบบ omni-inbox/1
  Note over C,D: ไม่แก้หรือลบไฟล์ใดเลย จึงชนกันไม่ได้
  S->>D: ทุก 3 ชม. อ่านไฟล์ทั้งหมด
  S->>V: รวมเข้า Claude log ติดป้าย (Chat) หรือ (Cowork)
  S->>V: vsync
  S->>D: sync สำเร็จแล้ว ย้ายไฟล์ไปถังขยะ (Google ลบถาวรเองใน 30 วัน)
```

รูปแบบไฟล์ (อยู่ใน skill `save-to-log`, สำเนาที่ `docs/vault/chat-skill/` ใน repo omni-task):

```
omni-inbox/1
from: chat
saved: 2026-10-21T21:40:00+07:00
project: siriraj/ป้าย

## ภาพรวม
- siriraj/ป้าย: ถึงไหน ➜ ใครทำต่อ

## งานค้าง
- [ ] #siriraj/ป้าย #kluido สิ่งที่ Klui ต้องทำ

## ไทม์ไลน์
- ทำอะไร ตัดสินใจอะไรเพราะอะไร

## รู้จักเพิ่ม
- สิ่งที่เพิ่งรู้เรื่องวิธีทำงานหรือใช้ชีวิตของ Klui (ไม่ต้องมีก็ได้)
```

หัวข้อ `## รู้จักเพิ่ม` ไม่บังคับ เลขาเอาบรรทัดใต้หัวข้อนี้ไปใส่ `Omni/Claude รู้จักคุณ.md` ไม่ใส่ใน Claude log

ทางเร่ง: ถ้า Claude Chat export ไฟล์ .md หลังคุยเสียง (รูปแบบ omni-inbox/1 หรือแค่รายการงาน) Klui แนบไฟล์ในห้องเลขาแล้วพิมพ์ "รอบเลขา" ได้เลย เลขาอ่านทันที งานของ Klui ลงท้าย `Omni note.md` เป็นบรรทัดเปล่า และบรรทัดใต้ `## รู้จักเพิ่ม` ไปที่ `Claude รู้จักคุณ.md`

## 5. กติกาแท็กโปรเจกต์ (ทำไมงานถึงขึ้นหรือไม่ขึ้นใน Ygdrasil)

Ygdrasil และหน้าโปรเจกต์แสดงเฉพาะงานที่ **แท็กแรก** เป็นโปรเจกต์ที่ Klui เลือกไว้ในหน้าโปรเจกต์ แท็กอื่นเป็นแท็กธรรมดา กิ่งเขียนต่อด้วย `/` เช่น `#peddose/แอป/มือถือ`

```mermaid
flowchart TD
  NEW["งานใหม่จากผู้ช่วย Claude หรือมือ"] --> FIRST{"แท็กแรกเป็นโปรเจกต์<br/>ที่เลือกไว้หรือไม่"}
  FIRST -->|ใช่| TREE["ขึ้นใน Ygdrasil<br/>ใต้โปรเจกต์หรือกิ่งนั้น"]
  FIRST -->|ไม่ใช่ หรือไม่มีแท็ก| LOST["ไม่ขึ้นใน Ygdrasil<br/>อยู่ในรายการงานเท่านั้น"]
  LOST --> FIX1["แก้: สั่งผู้ช่วย 'ย้ายงาน X ไปโปรเจกต์ Y'"]
  LOST --> FIX2["แก้: หน้าโปรเจกต์ กดเพิ่มแท็กนั้นเป็นโปรเจกต์"]
```

- ผู้ช่วยในแอปได้รับรายชื่อโปรเจกต์และกิ่งทั้งหมดทุกครั้ง และต้องเลือกจากรายการนั้น ไม่แน่ใจต้องถาม (`AiAssist.projectList` และกติกาใน `CHAT_ASK`, repo omni-task `shared/.../model/AiAssist.kt`)
- ถ้า Klui กดยืนยันงานที่ใช้โปรเจกต์ใหม่ แอปเพิ่มโปรเจกต์นั้นเข้ารายการที่เลือกไว้เอง (`keepProject` ใน `TaskViewModel.kt`)
- Claude ที่เพิ่มงานลง `Omni note.md` ใส่แท็กโปรเจกต์ก่อน แล้ว `#kluido` ตามกติกาใน `CLAUDE.md` ยกเว้นงานจากไฟล์ที่ Klui แนบในห้องเลขา (ทางเร่ง: export จาก Live แล้วพิมพ์ "รอบเลขา") เลขาเพิ่มเป็นบรรทัดเปล่า `- [ ] งาน ➕ วันที่` ไม่มีแท็ก ให้ขึ้นถาด "ยังไม่มีบ้าน" ในแอป

## 9. วงจรเรียนรู้ (loop of evolution)

ทุกการคุยและทุกการกดในแอปสอน Claude เรื่อง Klui เพิ่ม ความรู้เก็บในไฟล์ ไม่เก็บในความจำของแชต Klui เปิดดู แก้ หรือลบได้ทุกบรรทัด

```mermaid
flowchart LR
  A["Klui คุยเสียงกับ Claude<br/>หรือกดปุ่มในแอป"] --> B["จบด้วย 'บันทึก'<br/>ไฟล์ใหม่ใน Claude inbox<br/>มีหัวข้อ ## รู้จักเพิ่ม"]
  B --> C["เลขารวมทุก 3 ชม.<br/>5b: เพิ่มบรรทัดใน Claude รู้จักคุณ.md<br/>และดูแบบแผนจาก Claude log"]
  C --> D["Claude รู้จักคุณ.md<br/>ไม่เกิน 50 บรรทัด รวมบรรทัดที่คล้ายกัน"]
  D --> E["ทุกเซสชันอ่านตอนเริ่ม<br/>pretext ของแอปใส่ไปด้วย"]
  E --> A
```

- เขียนเฉพาะเรื่องวิธีทำงานหรือใช้ชีวิต (นิสัย แรง คอขวด สิ่งที่ช่วยได้) ไม่เขียนเรื่องงานชิ้นเดียว
- รูปแบบบรรทัด: `- <สิ่งที่รู้> (YYYY-MM-DD, จาก <คุยเสียง | ห้องเลขา | ปุ่มในแอป | Claude log>)` ใหม่สุดอยู่บน เมื่อมีของใหม่แทนของเก่าเขียน `- เปลี่ยน: ...` และลบบรรทัดเก่าเฉพาะที่ Claude เขียนเอง
- เลขาอ่านเฉพาะที่จำเป็นในแต่ละรอบ (ภาพรวม งานค้าง ไทม์ไลน์ 7 วัน ไฟล์ใหม่ และโน้ตนี้) เพื่อให้เซสชันเล็ก

## 10. ปิดเดือนและแผนระยะยาว

- รอบแรกของเดือนใหม่: เลขาย้ายวันของเดือนก่อนที่ยังค้างใน Claude log ไปไฟล์เดือน (`Claude/log/<ปี>/<MM Mon>.md`) เขียนสรุปรายโปรเจกต์ไว้บนสุดของไฟล์เดือน และเพิ่มบรรทัดสรุปเดือนใต้วันนี้ใน Claude log จากนั้นปิดเดือนใน `log/index.md` ตามเดิม
- `Claude/แผนระยะยาว.md`: Klui กรอกเป้าหมายรายไตรมาส (เป้าหมาย ทำไม วัดผลยังไง เส้นตาย) ทุกวันอาทิตย์รอบแรก ถ้ามีเป้าหมาย เลขาเทียบกับงานที่ทำจริงในสัปดาห์นั้น แล้วเขียนหนึ่งบรรทัดในภาพรวมว่า `ตามแผน` หรือ `เริ่มหลุด` พร้อมบอกว่าใครทำต่อ

## 11. หมุนห้องเลขาทุกเดือน

ห้องเลขา (เซสชันคลาวด์ที่ตารางเวลาปลุก) ควรเปลี่ยนเป็นเซสชันใหม่ต้นเดือนทุกเดือน ทำได้อย่างปลอดภัยเพราะไม่มีอะไรสำคัญอยู่ในแชต ทุกอย่างอยู่ในไฟล์ (secretary.md, state, Claude log, Claude รู้จักคุณ.md) และห้องเก่าที่ยาวขึ้นเรื่อย ๆ จะช้าและแพงขึ้น

การหมุนต้องมี Klui (หรือเซสชัน Claude ที่ Klui สั่ง) ชี้ตารางเวลาไปที่ห้องใหม่ ตามหัวข้อ "ซ่อมเลขา" ใน `Claude/README.md` ระบบนี้ไม่เปลี่ยนตารางเวลาเอง
