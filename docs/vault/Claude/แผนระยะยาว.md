# แผนระยะยาว

Klui กรอกเอง เป้าหมายระยะยาวแบ่งตามไตรมาส ทุกวันอาทิตย์รอบแรก เลขาอ่านโน้ตนี้ เทียบกับงานที่ทำจริงในสัปดาห์นั้น แล้วเขียนหนึ่งบรรทัดในภาพรวมของ Claude log ว่าตามแผนหรือเริ่มหลุด ถ้ายังไม่มีเป้าหมายที่กรอกแล้ว เลขาไม่เขียนอะไร

เลขาไม่แก้โน้ตนี้ มีแต่ Klui (หรือ Claude เมื่อ Klui สั่ง) ที่แก้
