# Claude รู้จักคุณ

โน้ตนี้เก็บสิ่งที่ Claude รู้เกี่ยวกับวิธีทำงานและวิธีใช้ชีวิตของ Klui เพื่อให้ Claude ช่วยได้ตรงขึ้นทุกครั้งที่คุย ทุกการคุยและทุกการกดในแอปสอนอะไรเพิ่ม แล้วเขียนไว้ที่นี่ ไม่เก็บไว้ในความจำของแชต

- Klui แก้หรือลบบรรทัดไหนก็ได้ทุกเมื่อ
- Claude อ่านโน้ตนี้ตอนเริ่มทุกเซสชัน และเลขาเพิ่มบรรทัดใหม่ทุกรอบเมื่อเห็นสิ่งที่ใช้ได้นาน
- เขียนเฉพาะเรื่องวิธีทำงานหรือใช้ชีวิต (นิสัย แรง คอขวด สิ่งที่ช่วยได้) ไม่เขียนเรื่องงานชิ้นเดียว
- Claude แตะเฉพาะบรรทัดที่ตัวเองเขียนในรูปแบบข้างล่าง บรรทัดที่ Klui เขียนเองหรือขึ้นต้นด้วย 💬 ไม่ถูกแก้หรือลบ
- ไม่เกิน 50 บรรทัด ถ้าเกิน Claude รวมบรรทัดที่คล้ายกัน

รูปแบบหนึ่งบรรทัด ใหม่สุดอยู่บน เป็นบูลเล็ตธรรมดา (ไม่มีช่องติ๊ก แอปจึงไม่นับเป็นงาน):

```
- <สิ่งที่รู้ ประโยคเดียว> (<YYYY-MM-DD>, จาก <ที่มา>)
- เปลี่ยน: <สิ่งที่รู้ใหม่ แทนของเดิม> (<YYYY-MM-DD>, จาก <ที่มา>)
```

ที่มา: คุยเสียง, ห้องเลขา, ปุ่มในแอป, Claude log, สัมภาษณ์ <วันที่>

## ที่ Claude รู้

- อยากได้เลขาที่กรองให้ว่าอะไรด่วนจริงและควรทำวันนี้ เพื่อไม่ต้องคิดซ้ำทุกเช้าและกังวลน้อยลง (2026-10-22, จาก สัมภาษณ์ 2026-10-22)
- เคยลอง TickTick และเมทริกซ์ไอเซนฮาวเวอร์แล้วเลิก เพราะทุกงานดูสำคัญไปหมดและไม่มีใครช่วยจัดลำดับ (2026-10-22, จาก สัมภาษณ์ 2026-10-22)
- ใช้ชีวิตวันต่อวัน ไม่วางแผนรายสัปดาห์ และไม่อยากมองไกลเกินพรุ่งนี้ (2026-10-22, จาก สัมภาษณ์ 2026-10-22)
- การจดงานเป็นคอขวด จึงจำไว้ในหัวหรืออัดเสียงก่อน เพราะการตั้งวันที่และเวลาใช้เวลา อยากจดหยาบก่อนแล้วจัดทีหลัง (2026-10-22, จาก สัมภาษณ์ 2026-10-22)
- วันที่ ⏳ และ 📅 ส่วนใหญ่ตั้งเอง ไม่ใช่กำหนดส่งจริง เมื่อเลยกำหนดจึงปล่อยเป็นสีแดงแล้วไปทำอย่างอื่นที่รู้สึกสำคัญกว่า (2026-10-22, จาก สัมภาษณ์ 2026-10-22)
- มักประเมินเวลาน้อยไป เพราะเริ่มทำเลยโดยไม่แตกงานย่อย งานย่อยที่ซ่อนอยู่โผล่ระหว่างทางจนกลายเป็นงานก้อนเดียวยาว (2026-10-22, จาก สัมภาษณ์ 2026-10-22)
- ชีวิตแบ่งสองแบบตามเวร วันมีเวรดึกนอนราว 21.00 ถึง 22.00 น. ตื่นราว 01.45 น. วันธรรมดานอนราว 22.00 ถึง 23.00 น. ตื่นราว 07.45 น. (2026-10-22, จาก สัมภาษณ์ 2026-10-22)
- งานประจำ 08.30 ถึง 16.30 น. กินเวลาเกือบทั้งหมด จึงแทบไม่มีที่ว่างทำโปรเจกต์ส่วนตัวและทำงานคนเดียวเป็นส่วนใหญ่ (2026-10-22, จาก สัมภาษณ์ 2026-10-22)
