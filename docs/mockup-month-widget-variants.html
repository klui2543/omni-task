A. โปร่ง เน้นตัวเลข

ตัดเส้นตารางและชื่อ event ออกหมด เหลือจุดสีใต้วันที่ (สีตามปฏิทิน, เขียวคือ task) ด้านล่างโชว์สิ่งถัดไปบรรทัดเดียว

เหมาะกับ คนที่อยากเห็นภาพรวมเดือนแบบสบายตา ลายมือกับ Emoji เด่นชัดที่สุดเพราะพื้นว่าง
ข้อเสีย ต้องแตะเข้าไปดูว่าวันนั้นมีอะไร

B. สมุดสติกเกอร์

พื้นสีกระดาษ แต่ละวันเป็นการ์ดมุมมน Emoji ตัวใหญ่กลางช่อง เส้นสีด้านล่างบอกว่ามี event อารมณ์แบบ diary

เหมาะกับ ใช้ Emoji บันทึกอารมณ์หรือเรื่องสำคัญรายวัน ใกล้ฟีล Samsung ที่สุดตอนติดสติกเกอร์
ข้อเสีย สีสว่างต่างจากธีมมืดของแอป (ทำเวอร์ชันมืดได้)

C. เดือนเล็ก กับรายการข้างล่าง

ปฏิทินกะทัดรัดด้านบน ขีดเขียวใต้วันที่มีงาน ด้านล่างเป็นรายการวันนี้และพรุ่งนี้ ใช้ขนาด 4x5

เหมาะกับ ใช้งานจริงทุกวัน เห็นทั้งเดือนและสิ่งที่ต้องทำในที่เดียว แตะวงกลมเพื่อติ๊ก task ได้
ข้อเสีย พื้นที่วาดเล็กลง ลายมือจะอยู่ในส่วนเดือนเท่านั้น

D. แถบ event แบบโปร่ง

ยังมีชื่อ event เหมือน Samsung แต่จำกัดวันละ 1 แถบ ที่เหลือเป็น +2 แถบมน ตัวอักษรใหญ่ขึ้น ไม่มีเส้นตาราง

เหมาะกับ คนที่อยากอ่านชื่อ event ได้จาก widget ทันที ใกล้แบบเดิมที่สุดแต่หายใจได้มากขึ้น
ข้อเสีย ยังแน่นกว่า A กับ B เมื่อเดือนมีงานเยอะ
