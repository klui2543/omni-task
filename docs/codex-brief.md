# Brief สำหรับ Codex: UI และ Art design ของ Omni Quest

## 1. งานนี้คืออะไร

Omni Quest คือเกม Idle RPG ในแอป Omni Task (Android, Kotlin, Jetpack Compose) ตัวละครเก่งขึ้นจากงานจริงที่เจ้าของทำเสร็จใน Obsidian vault ระบบเกมและเนื้อเรื่องเสร็จแล้ว CI ผ่าน แต่**โครงการพักไว้เพราะ AI วาด sprite ให้ตรง brief และสม่ำเสมอกันไม่ได้** ตอนนี้ทุกภาพเป็นของชั่วคราว (emoji และตัวละครที่วาดด้วยโค้ดแบบง่าย)

**งานของคุณ:**
1. กำหนด art direction และทำภาพจริงของเกม ด้วยวิธีที่ได้ผลสม่ำเสมอ (ข้อ 5)
2. ปรับ UI ของหน้าจอเกมให้สวย อ่านง่าย และเข้ากับแอป Omni (ข้อ 6)

**ห้ามเปลี่ยน:** ตรรกะเกม สูตร XP เควส และบทพูด ยกเว้นจำเป็นต่อ UI และต้องบอกเหตุผล

## 3. กฎที่ต้องทำตาม (จาก `CLAUDE.md`)

- **ข้อความที่ผู้ใช้เห็นห้ามมีขีดยาว `—` และจุดกลาง `·`** เลย ใช้การขึ้นบรรทัด จุลภาค ทวิภาค วงเล็บ หรือเว้นระยะระหว่าง element แทน (`StoryTest` ตรวจบทพูดให้แล้ว)
- **ข้อความใน UI เป็นภาษาไทยก่อน** ใช้ `tr("ไทย", "English")` เหมือนส่วนอื่นของแอป
- **ไม่มี Android SDK ในเครื่อง:** build และทดสอบผ่าน GitHub Actions เท่านั้น
  - สั่ง workflow `Build APK` (`.github/workflows/build.yml`) แบบ `workflow_dispatch` บน branch ของคุณ
  - รอบบน branch จะไม่ปล่อย release
  - ต้องผ่านทั้ง Unit tests, Android emulator และ build APK
  - `CalendarSyncTest` บน emulator เคยพังแบบสุ่มครั้งหนึ่ง ถ้าพังให้รันซ้ำ 1 ครั้งก่อนสรุป
- **`shared/` เป็น Kotlin Multiplatform (JVM และ JS):** ห้ามใช้ `java.time` หรือ API ที่มีแต่บน JVM ทดสอบด้วย `gradle :shared:allTests` (ไม่ต้องใช้ Android SDK)
- **ห้าม commit keystore** หรือข้อมูลส่วนตัวจาก vault
- **รูปภาพที่เก็บใน vault** ต้องเป็น WebP ใน `📁 Folder/หลังบ้าน/Attachments` (แต่ภาพของเกมควรอยู่ในแอป ไม่ใช่ใน vault)

## 5. Art direction

### โจทย์ภาพ

- **แนว:** Idle Action RPG ได้แรงบันดาลใจด้านระบบจาก Ragnarok
- **ลายเส้น:** chibi น่ารัก เท่ และสวย
- **ห้ามใช้:** ภาพ ชื่อ หรือเพลงของ Ragnarok หรือเกมอื่น

**ต้องทำ:**

| ชิ้นงาน | จำนวน | รายละเอียด |
|---|---|---|
| ตัวละครผู้เล่น (paper-doll) | 1 ระบบ | ซ้อนชิ้นส่วน: ทรงผม 5 แบบ, สีผม 6, สีผิว 4, สีชุด 5 และอาวุธที่ใส่อยู่ (ดู `QuestWorld.hairStyles` และรายการสีต่างๆ) ต้องมีท่ายืน ท่าโจมตี และท่าเด้งเบาๆ ตอน idle |
| Mascot ประจำเผ่า | 5 ตัว | โฮมุระ (ลูกมังกรไฟตัวกลม), มิมิ (นกฮูกดาวสวมแว่น), ฟุ้ง (จิ้งจอกหางเมฆ), ปุยฟอง (วาฬน้อยลอยฟ้า), ต้นกล้า (กวางน้อยเขาเป็นกิ่งไม้) ใช้สีประจำเผ่าจาก `Tribe.color` |
| NPC (ภาพหน้าตอนคุย) | 3 ตัว | มาสเตอร์ออร์ริน (หัวหน้ากิลด์ อดีตนักผจญภัย ขาเจ็บ ใจดี), ลีโอ (นักดาบเผ่าอัคนี ผมแดง ขี้อวด), เซลีน (จอมเวทเผ่าจันทรา ผมเงิน ถือสมุด) |
| ศัตรู | ราชาผัดวัน 1 ตัว และมอนสเตอร์ 15 ตัว | ราชาผัดวันเป็นร่างหมอกสวมมงกุฎ มอนสเตอร์ 5 โซน โซนละ 3 ตัว ตามชื่อใน `Idle.zones` |
| ไอคอนไอเทม | 19 ชิ้น | ตาม `QuestWorld.items` |
| ฉากหลังโซน | 5 แบบ | ป่าหมอกจาง, ถ้ำแจ้งเตือน, หอคอยเอกสาร, ปราสาทผัดวัน, ยอดยกดราซิล |

### วิธีทำที่แนะนำ

ตัวที่เคยล้มเหลวคือการสั่ง AI สร้างภาพทีละรูป เพราะได้ลายเส้นไม่ตรงกันและไม่ตรง brief **แนะนำให้ทำภาพเป็นโค้ดหรือข้อมูลที่ควบคุมได้ 100%** เลือกทางใดทางหนึ่ง (หรือผสม) แล้วอธิบายเหตุผล

| ทาง | ทำอย่างไร | ข้อดี | ข้อเสีย |
|---|---|---|---|
| **ก. Pixel art เป็นข้อมูล** | sprite ขนาด 32x32 หรือ 48x48 เก็บเป็นตารางตัวอักษรกับ palette ใน Kotlin (เช่น `shared/.../quest/Sprites.kt`) แล้ววาดด้วย Compose Canvas แบบไม่เบลอ (nearest neighbor) | ฟีล Ragnarok ชัด, สม่ำเสมอทุกตัว, เปลี่ยนสีผม สีผิว และสีชุดได้แค่สลับ palette, ไฟล์เล็ก, ทดสอบได้ | ต้องออกแบบทีละพิกเซล |
| **ข. Vector** | SVG หรือ Android VectorDrawable ใน `app/src/main/res/drawable` แยกชิ้นส่วนสำหรับ paper-doll | คม ปรับขนาดได้, chibi สวย | ต้องคุมสไตล์ให้คงที่ทุกชิ้น |
| **ค. Asset pack สำเร็จรูป** | ซื้อหรือใช้ pack ที่ license อนุญาต | เร็ว | ต้องหา pack ที่มีครบทุกชิ้นและลายเส้นเดียวกัน |

ถ้าเลือก ก หรือ ข ให้ทำ **style guide ใน `docs/art-style.md` ก่อนวาด** ระบุ palette ต่อเผ่า, สัดส่วนตัว chibi (หัวต่อตัว), ความหนาเส้น, แสงเงา และตัวอย่าง 1 ตัวที่เจ้าของอนุมัติแล้ว ค่อยทำตัวที่เหลือ

**เก็บใบอนุญาต** ของ asset หรือฟอนต์ใหม่ทุกชิ้นไว้ใน `licenses/` เหมือนฟอนต์ที่มีอยู่

## 6. UI

**ปรับหน้าจอเหล่านี้ใน `QuestScreen.kt`:**
- หน้าสร้างตัวละคร
- การ์ดตัวละคร
- แท็บทั้ง 6
- หน้า Idle (ฉากต่อสู้, HP bar, ตัวเลขดาเมจ, เอฟเฟกต์โจมตี)
- หน้าอ่านฉากเรื่อง (กล่องบทพูดพร้อมภาพหน้าตัวละคร)
- แถบบนหน้าโฟกัส

**ข้อกำหนด:**
- **ใช้ระบบสีและฟอนต์ของแอป** (`C.*`, `TS.*`, `AppFont`) ให้หน้าเกมกลมกลืนกับแอป สีประจำเผ่าใช้เป็นสีเน้น
- **ต้องดูดีทั้ง 3 ธีม** (midnight, graphite มืด, graphite สว่าง) และอ่านได้ (contrast พอ)
- **ขนาดจอ:** ใช้ได้ที่จอมือถือกว้าง 360dp ขึ้นไป และจอพับ ห้ามมี horizontal scroll
- **ภาษาไทย:** ข้อความไทยยาวต้องไม่ตกขอบ ไม่ทับกัน
- **ความลื่น:** animation ต้องลื่นแต่ประหยัดแบต หน้า Idle เปิดจอค้างไว้ระหว่างจับเวลา (`keepScreenOn`) จึงห้าม redraw หนักเกินจำเป็น
- **ปุ่มหลัก:** อยู่ในระยะนิ้วโป้ง (ครึ่งล่างของจอ)

## 7. เสร็จแล้วเมื่อ

1. **มี style guide** `docs/art-style.md` พร้อมภาพตัวอย่างที่เจ้าของอนุมัติ
2. **ไม่มี emoji ชั่วคราวเหลือ** ภาพทุกชิ้นในข้อ 5 อยู่ในแอปแทนแล้ว (`Tribe.emoji`, `ZONE_FOES`, `Item.icon`, `Chibi()`, `Speaker.emoji`)
3. **ไม่มีเทสต์ไหนพัง:** `gradle :shared:allTests` ผ่าน และ workflow `Build APK` บน branch ผ่านทุกขั้น
4. **มีภาพหน้าจอให้ดู:** ภาพหน้าจอจาก emulator หรือ Compose Preview ของ (สร้างตัวละคร, การ์ดตัวละคร, หน้า Idle, หน้าฉากเรื่อง) ทั้งธีมมืดและสว่าง แนบไว้ใน PR
5. **เปิด PR เข้า `main`** พร้อมสรุปเป็นภาษาไทย ไม่มีขีดยาวและจุดกลาง
